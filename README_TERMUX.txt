   unzip altabuki_pay_baseline_2026-10-01.zip -d ~/altabuki_pay

2) الدخول:
   cd ~/altabuki_pay

3) تشغيل الويب:
   bash TERMUX_RUN_WEB.sh

4) بناء APK:
   bash TERMUX_BUILD_APK.sh
